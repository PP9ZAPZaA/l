แบบฟอร์มขอเข้าและลงทะเบียนอุปกรณ์ห้อง Data Center

กรอกข้อมูลผู้เข้าปฏิบัติงาน รายการอุปกรณ์ที่นำเข้า และเลือกวัตถุประสงค์เพื่อยื่นตรวจสอบอนุมัติ

1. ข้อมูลผู้ขอเข้าปฏิบัติงาน (Requester Information)

2. กำหนดการและวัตถุประสงค์ (Schedule & Audit Purpose)

เงื่อนไขตรวจสอบพิเศษ (Special Compliance Check): คำร้องนี้จัดอยู่ในประเภทการสำเนา/ลบ/รีเซ็ต/สาธิต/ริบอุปกรณ์ เมื่อปฏิบัติงานเสร็จ เจ้าหน้าที่ IT Data Center จะทำการตรวจเช็คเงื่อนไขความปลอดภัยและบันทึกการทำลายหรือลบข้อมูลอย่างเคร่งครัดตามขั้นตอน Flowchart

3. รายชื่อผู้เข้าปฏิบัติงาน (VISITORS)

ชื่อ-นามสกุล (Visitor Name) เลขรหัสพนักงาน / เลขบัตรประชาชน จัดการ

4. รายการอุปกรณ์ที่นำเข้าห้อง Data Center (EQUIPMENTS)

ชื่ออุปกรณ์ / Serial Number (Item Name) จำนวนนำเข้า (Quantity In) จัดการ

รายการคำร้องและสถานะการตรวจสอบห้อง Data Center

ติดตามผลอนุมัติ ดูรหัสคำร้องสำหรับแจ้งเจ้าหน้าที่จุดตรวจ และดูประวัติการเข้า-ออก

ID คำร้อง ผู้ขอ / แผนก วัตถุประสงค์ ประเภทเงื่อนไข สถานะการตรวจสอบ (Status) วันที่ยื่น การดำเนินการ / รหัส Request Code

ศูนย์อนุมัติและตรวจสอบคำร้อง (IT Supervisor Approvals)

ตรวจสอบรายละเอียดคำร้อง ผู้เข้าห้อง รายการอุปกรณ์ และอนุมัติ/ไม่อนุมัติการเข้าห้อง Data Center

ID คำร้อง ผู้ขอเข้า รายละเอียดวัตถุประสงค์ จำนวนผู้เข้า จำนวนอุปกรณ์ การประเมินเงื่อนไข ผลการอนุมัติ
